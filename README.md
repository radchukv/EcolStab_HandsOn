Hands-on materials for the webinar on ecological stability for ecoinformatics group of IAVS. The webinar showcases the use of estar R package for measuring different components of ecological stability. Two datasets are used as case studies: 
- a dataset from ecotoxicological experiment where an insecticide was used to disturb species-rich aquatic invertebrate community, and
- a dataset from long-term survey of plant community in “Montagna di Torricchio” Strict Nature Reserve in Italy.

The workflow for the data from ecotoxicological experiment is found in EcolStability_AquaticCommunity.Rmd and the workflow for the plant community data in Stab_PlantData_Italy.Rmd.
